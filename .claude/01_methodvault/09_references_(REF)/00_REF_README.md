
REF files in this vault record what an **external** source says — a standard, a
specification, a paper — where a decision in `02_decisions_(DEC)` rests on it and
the wording matters enough that a citation in prose is not enough.

The folder is empty today, and that is a state rather than an omission. Every
external source the migrated decision record leans on (ISO 9000:2015 3.8.10,
CommonMark 0.31.2, the Obsidian help pages, the arXiv papers behind the
enforcement-layer decision) is cited inline in the decision that uses it, which
is where it was written and where it is read. A REF note earns its existence
when a second decision needs the same source and the two would otherwise quote
it differently.

The folder also carries the vault: `validate_vault.py` recognises a vault root
by three domain folders, and this is one of them.
